About

Food Scout is a multimodal, agentic food guide for Blok M, Jakarta, built only on free, real data: OpenStreetMap venues plus places discovered in YouTube food vlogs and web articles. An LLM structures the evidence, but code checks every quote and decides confidence.

  • High confidence: an OpenStreetMap tag, or 2+ independent sources. Medium: one source. Low: inferred, or a photo-only guess.
  • Locations are marked by precision: exact point, street, landmark (for example, inside Blok M Square), or just "somewhere in Blok M".
  • Trending now measures momentum over the last 60 days. New spots are places a source says just opened, or that were first mentioned in the last 120 days. Favorites are all-time.

Search and Vibe Match run in your browser (MiniLM and CLIP via transformers.js), so this site needs no server. The data refreshes weekly via GitHub Actions.

Signals come from public mentions and can be wrong or outdated. Check halal status at the venue.
